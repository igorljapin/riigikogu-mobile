# Riigikogu Mobile Dashboard - Claude Code Instructions

## Repository Purpose
Mobile PWA dashboard for the XV Riigikogu (101 MPs).
Hosted at https://igorljapin.github.io/riigikogu-mobile/

## File Map
- `index.html` - Shell: PWA meta tags, CDN script tags, SW registration.
  No hardcoded MP data; all data lives in `app/data.js`.
- `app/data.js` - Auto-generated by `scripts/fetch_mp_data.py`.
  Contains MPS array, PARTIES config, FACTION_MAP. Do not edit by hand.
- `app/chrome.jsx` - Design tokens, TopBar, TabBar, ChromeApp root (Chunk 1).
- `app/parliament.jsx` - Parliament screen: seat balance, party grid, board (Chunk 3).
- `app/sheets.jsx` - Bottom sheet system: MPSheet, PartyMPsSheet (Chunk 4).
- `app/members.jsx` - Members list screen with search (Chunk 5).
- `app/calculator.jsx` - Coalition calculator screen (Chunk 6).
- `mp-data-scraped.json` - Legacy photo/profile lookup. Superseded by `app/data.js`.
- `data/mp_data_current.json` - Committed baseline used for monthly diff comparison.
- `data/board.json` - Riigikogu board members and roles.
- `data/mp_data_fetched.json` - Temporary file created by workflow. Never commit to main.
- `data/change_report.json` - Output of comparison script. Read before making changes.

## Monthly Update Procedure

Run `scripts/fetch_mp_data.py` — it regenerates both `data/mp_data_current.json` and
`app/data.js` in one step. Commit both files and open a PR. No manual seat-count
arithmetic required; the script handles all totals automatically.

If the script reports party switches, flag them in the PR description for human review
before merging (politically significant changes).

PR title format: "MP Data Update - [Month YYYY]"
Target branch: main

## Critical Rules
- This repo uses a deliberate sanctioned design. Changes require a PR.
- Never commit directly to main - always use a feature branch.
- Do not modify manifest.json or .github/workflows/ without explicit instruction.
